# CareFlow Power BI Dashboard

## Project Overview
CareFlow is a Clinical Pathway Process Mining project focused on analyzing patient journeys and healthcare operations.

## Dashboard Objectives
- Analyze total patients and events.
- Understand activity frequency.
- Identify process bottlenecks.
- Analyze process conformance and non-compliant cases.

## Dashboard Pages
1. Project Overview
2. Process Discovery
3. Bottleneck Analysis
4. Conformance Analysis

## Tools Used
- Power BI
- Python
- SQL
- Excel
- PM4Py

## Data Source
Cleaned healthcare event log and process mining reports.
