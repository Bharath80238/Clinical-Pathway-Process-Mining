CareFlow: Clinical Pathway Process Mining

Project Overview

CareFlow is a healthcare data analytics project that uses patient event-log data to understand and analyze clinical pathways. The project aims to discover how patients move through different healthcare activities, identify potential delays and bottlenecks, and generate insights that may help improve healthcare process efficiency.

The project uses data analysis techniques, Python, SQL, and data visualization to explore clinical event data and present meaningful findings through a dashboard.

Objectives

* Understand and explore healthcare event-log data.
* Identify missing values, duplicate records, and data quality issues.
* Analyze patient cases and the frequency of clinical activities.
* Study the time between activities to identify potential delays.
* Discover common patient pathways and repeated activities.
* Calculate relevant key performance indicators (KPIs).
* Create visualizations and dashboard-ready results.
* Present findings and recommendations based on the data.

Tools and Technologies

* Python: Data inspection, cleaning, and analysis.
* SQL: Querying records, analyzing activities, and calculating metrics.
* Pandas: Data manipulation and preparation.
* Excel / Power BI: Dashboard development and visualization.
* Git and GitHub: Version control, documentation, and project collaboration.

Project Workflow

1. **Data Collection:** Identify and document the dataset source.
2. **Data Exploration:** Understand the dataset structure, columns, and records.
3. **Data Quality Assessment:** Check missing values, duplicates, and timestamp consistency.
4. **Data Preparation:** Clean and prepare data where necessary.
5. **SQL Analysis:** Analyze case counts, activity frequency, and time intervals.
6. **Process Mining:** Explore activity sequences, repeated activities, and potential bottlenecks.
7. **KPI Development:** Calculate metrics supported by the available data.
8. **Dashboard Development:** Present results through charts, KPI cards, and filters.
9. **Reporting:** Document findings, limitations, and recommendations.

Key Performance Indicators (KPIs)

The following KPIs will be evaluated based on the available dataset fields:

* Total number of cases.
* Total number of recorded events.
* Number and frequency of activities.
* Average case duration, if timestamps support the calculation.
* Time between consecutive activities.
* Most frequent activity sequences.
* Repeated activities and potential process bottlenecks.

These metrics will be calculated and reported after data validation. No results are assumed in advance.

Expected Deliverables

* Dataset source documentation.
* Data dictionary and data quality report.
* Python scripts or notebooks for data analysis.
* SQL queries and analysis results.
* Process analysis and visualizations.
* Dashboard with relevant KPIs.
* Final findings and recommendations.
* Project documentation and presentation.

Project Timeline

**Planned duration:** One month

The project will be developed in stages, including dataset exploration, data quality assessment, SQL analysis, KPI development, visualization, and final documentation.

Team Contributions

The project involves collaboration across data collection and cleaning, SQL and data analysis, process mining, and dashboard development. Individual contributions will be documented through meaningful GitHub commits.

Conclusion

CareFlow aims to demonstrate how healthcare event-log data can be analyzed to understand clinical pathways, investigate process delays, and communicate data-driven insights. The final conclusions will be based on the results of the analysis and the limitations of the dataset.
